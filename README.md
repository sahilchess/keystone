# keystone
a custom mechanical keyboard: cherry mx switches, rp2040?, oled, rgbs and more????

## demo
1. go to https://kicanvas.org/?repo=https%3A%2F%2Fgithub.com%2Fsahilchess%2Fkeystone
2. wait for it to load the repo
3. click on the schematic or pcb file in the sidebar to view it
4. use your mouse to pan and scroll to zoom
